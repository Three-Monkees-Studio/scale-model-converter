# Scale Model Converter
A free, offline-friendly 3D printing scale calculator by Three Monkees Studio. Enter your model's starting scale and target scale to get the percentage for your slicer's uniform scaling setting.

Launch the Scale Model Converter

Features
- Instant 3D printing scale percentages, including custom scales.
- Handy quick-pick conversions and one-click percentage copy.
- Favourite and recent conversions saved locally in your browser.
- Responsive layout for desktop, laptop, tablet and mobile.
- Free to use, no sign-in or subscription required.
How to use
1. Enter a starting scale, for example 1:35.
2. Enter your target scale, for example 1:16.
3. Set your slicer's uniform scale to the displayed percentage: 218.75% in this example.
Calculation: Starting scale denominator ÷ target scale denominator × 100.
